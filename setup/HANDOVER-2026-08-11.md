## 5. Things that will surprise the next session

- **`L1.3d` will now report ~204 games with no identity**, not 120. NFLAR 2034's games were all
  recreated and `f_games` never covered weeks 10–16. Expected, not a regression.
- **NFLAR 2034 game ids from this conversation are gone** — 9802, 9879, 9961, 7332 and so on.
  That season now starts at 10054.
- **`franchises.label` is a present-day snapshot**, not history. Franchise 2014 reads "Dallas
  Cowboys" across 394 fixtures actually played as Washington Commanders. Never use it for
  anything historical.
- **In-league season is not the calendar year** and cannot be calculated from a date. Read it
  from `games.week_id → weeks → seasons.year`.
- **The sentinel weeks (95/98/99) are the record** for NFLAR pre-2004, not an artefact to filter
  out.

## 6. Working practices adopted this session

- **A found bug gets fixed or logged, never just mentioned** (`lessons.md` §21). Eight were
  found today; three fixed, five documented.
- **When recording a code fix, name the file, the line, and what a passing check looks like.**
  §9 described a fix in detail and half of it was never applied — the entry was treated as
  evidence when only the file is.
- **Check the shape, not the total.** A row count going up is not evidence of correctness.
